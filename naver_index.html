일괄 입찰가 변경폭 +10%

항목별 시뮬레이션 · 추천 변경폭 "예상" 컬럼 = 위 일괄 변경폭 적용 시 · 추천은 신뢰도에 따라 변경폭을 제한(높음 ±50% · 중간 ±20% · 낮음 ±10%) · 헤더 클릭 정렬

개별 상세 — 변경폭별 예상 곡선 항목을 선택하면 -50% ~ +100% 구간의 예상 성과 · 노란 행 = 추천 변경폭

시뮬레이션 정확도를 높이는 데이터 수집 가이드

  • 일별 × 키워드(쇼핑은 소재) × PC/모바일 다차원 보고서를 최소 4주, 가능하면 8주 이상 올려주세요. 14일 이상이면 요일 효과를 자동 보정합니다.
  • 입찰가는 한 번에 10~20%씩 바꾸고 5~7일 유지하세요. 여러 입찰 구간의 실측이 쌓일수록 항목별 탄력성 신뢰도가 "높음"으로 올라갑니다.
  • 입찰가를 바꾸는 기간에는 소재·예산·랜딩페이지를 같이 바꾸지 마세요. 효과가 섞여 탄력성이 왜곡됩니다.
  • 입찰가 변경 기록(날짜·대상·변경 전/후 입찰가)을 남기면 "CPC 반영률"을 추정값이 아닌 실측값으로 바꿀 수 있습니다.
  • 최근 2~3일은 전환이 아직 덜 잡혔을 수 있어, 분석 기간 끝을 며칠 앞당기면 더 정확합니다.
  • 파워링크 키워드는 API 자동 수집 시트(설치 가이드: 네이버_API수집_설치가이드.html)의 예상실적 · 입찰가이력 CSV를 함께 올리면, 해보지 않은 입찰 구간까지 네이버 예상 데이터로 보정되고 추천 입찰가(원)가 표시됩니다. 신뢰도에 "네이버 예상"으로 표시돼요.
ⓘ 계산 방식 보기
· 변경 후 CPC = 현재 CPC × (1 + 입찰 변경폭 × CPC 반영률). 실제 CPC는 입찰가 이하에서 경쟁 상황에 따라 정해져, 입찰가를 올린 만큼 다 오르지 않는 경우가 많아 반영률(기본 80%)을 둡니다
· 변경 후 클릭 = 현재 클릭 × (CPC 변화율)탄력성. 탄력성은 항목의 일별 (CPC, 클릭) 로그 회귀로 추정하고, 데이터가 부족하면 계정 평균값 → 기본값 0.7 순으로 대체합니다
· 평균 노출순위가 1.5 이내(이미 최상위)면 입찰 상향 시 클릭 증가 여지가 적어 탄력성을 30%로 낮춰 계산합니다
· 전환·매출은 전환율과 객단가가 유지된다고 가정해 클릭에 비례시킵니다 · 추정손익 = 매출 × 마진율 − 광고비
· 신뢰도 네이버 예상: API 예상실적 곡선(입찰가 0.5~2배)의 클릭·CPC 변화 비율을 우리 실제 실적에 곱해 계산 (탄력성·반영률 대신 사용, 키워드 단위) / 높음: 자체 이력 7일↑ · CPC 변동 7%↑ · 설명력(R²) 0.15↑ / 중간: 계정 평균 탄력성 적용 / 낮음: 데이터 부족으로 기본값 적용
· 관측된 CPC 범위를 벗어나는 변경은 실제 결과와 차이가 커질 수 있습니다 (상세 곡선에 관측 범위 표시)
